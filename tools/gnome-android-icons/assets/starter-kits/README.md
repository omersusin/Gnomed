# Starter skeletons (CC0)

Generated by `python3 scripts/gnome_kit.py skeleton <kind> <out.svg> --color '#hex'`.
Each is a correct GNOME construction (template size, chin, chin gradient, glyph
lift) with a placeholder rounded-square glyph. Prefer writing a `build.py` with
`gnome_kit`; open these in Inkscape if you want to edit by hand.

| file | construction |
|---|---|
| `disc.svg` | Sound Disc: d118 face, 2 px chin, curvature light |
| `rimmed.svg` | Adwaita rim + recessed inner disc (Clocks/Mousai) |
| `square.svg` | 104 plate, r 8, 4 px chin |
| `portrait.svg` | 88 x 112 plate |
| `landscape.svg` | 112 x 88 plate |
