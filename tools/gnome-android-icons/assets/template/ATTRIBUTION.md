# HIG-app-icons assets

Copied unmodified from the user-supplied `HIG-app-icons-master.zip`
(upstream: https://gitlab.gnome.org/Teams/Design/HIG-app-icons).

- `hig-template.svg` - GNOME Design Team, RDF metadata states CC BY-SA 4.0.
  It is a construction template (guides, baseplate, grid) - never export it as an icon.
- `gnome-hig-palette.gpl` / `.css` - the 45-swatch GNOME HIG palette (9 families x 5).
  Licence not stated in these files; treat as GNOME Design Team material and attribute.

landscape 111x87 (8.5..119.5 x 28.5..115.5), baseline y = 117, 2 px grid.
